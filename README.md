# 8085 Microprocessor – Assembly Language Lab

This repository contains **8085 Microprocessor Assembly Language (ASM) programs** developed as part of Microprocessor Laboratory experiments.

It includes practical implementations of arithmetic and logical operations, memory manipulation, stack operations, interrupt handling, and basic algorithms using the 8085 instruction set.

## Technologies
- **Processor:** Intel 8085
- **Programming Language:** 8085 Assembly Language
- **File Format:** `.asm`
- **Platform:** 8085 Microprocessor Simulator / Hardware Kit

## Topics Covered
- Arithmetic Instructions
- Logical Instructions
- Data Transfer Instructions
- Stack Operations
- Memory Addressing
- Interrupt Handling (RST 7.5)
- Fibonacci Series
- Array Processing

## Purpose
To understand the 8085 architecture, instruction set, registers, memory operations, and low-level programming through practical assembly language experiments.
